## Activation and renderer ownership

- Each station starts with its existing photograph. The stage needs at least 35% viewport intersection for 500 ms in a visible document before it can acquire a renderer. The first usable draw happens behind the photograph and triggers the existing crossfade. The stage dimensions stay stable. An initial section fragment is resolved after React mounts, then follows the same visibility rule.
- Automatic requests are blocked by reduced motion, Save-Data, offline status, reported 2G or 3G service, reported downlink below 1.5 Mbps, reported memory of 4 GB or less, two or fewer logical processors, or missing WebGL2. Unreported optional device and network signals are treated as unknown. The automatic WebGL context requests `failIfMajorPerformanceCaveat`. The existing manual capability rules still apply, including the Save-Data block and reduced-motion rendering.
- A single synchronous lease covers runtime import, asset loading, and rendering. The queue gives a free lease to the eligible station with the earliest dwell deadline. Stations observed in the same frame tie in page order. A ready automatic owner keeps the lease while its stage is in view, with a 250 ms release delay after it leaves. Trusted pointer and keyboard holds in the station defer release until they end. Recent pointer, keyboard, click, and wheel input adds a 500 ms grace period. Waiting stations request their models only after claiming the lease.
- An explicit activation takes priority and pins ownership until Close, failure, unmount, or another explicit activation. Revocation aborts the current attempt and disposes its renderer before the next claim. The manual request revision and per-attempt abort checks reject stale imports, fetches, decoded assets, and frame publication. Section state retains the selected Anatomy layer, Switch Lab profile and presentation, and Build Studio configuration across renderer handoffs.
- Leaving eligibility cancels a pending automatic load. Close and Cancel suppress automatic reopening for that station until the page reloads, including across the in-page design-system route. Asset failure or context loss returns to photography with explicit Retry. A JavaScript import already in flight may finish after cancellation. The revoked attempt cannot start further model work or publish a frame.
- Default first visits open Anatomy in Exploded, Switch Lab in Cutaway, and Build Studio assembled in the Studio ¾ view. Audio stays off until the visitor selects Enable sound.

Positive lifecycle cases fixed the browser-reported connection at 4G and 10 Mbps for repeatability. The ordinary Hero check used native browser signals, and the production smoke suite separately checked six responsive widths from 320 to 1440 px.
