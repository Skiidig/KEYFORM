# KEYFORM — Development Roadmap

Each phase ends with a concrete verification gate and user approval before advancing.

| Phase | Name | Scope & Primary Deliverables | Exit Criteria |
| :--- | :--- | :--- | :--- |
| **KF-001** | **Project Foundation & Product Architecture** | Verify workspace & Git, define KF—01 product spec (verified standards vs. fictional specs), mechanical hierarchy, creative direction, website IA, minimal tech stack, asset pipeline, and roadmap. | All foundation docs internally consistent, local Git checkpoint committed, and phase approval received. |
| **KF-002** | **Blender Master Modeling (`KF—01`)** *(Approved)* | Build the editable external master, canonical 81-key layout, all nine assemblies and controls, and eight neutral review stills. | Validate placement and motion, document intended contacts, and obtain geometry and product design approval. Local checkpoint `ac4cbaf`. |
| **KF-003A** | **Targeted Refinement & Cycles Look Development** *(Provisional approval)* | Refine cap surfaces and skirt, case highlights, encoder knurl, and a separate hero switch. Develop procedural materials and both studio rigs. | Regression checks and seven Cycles stills complete. Finishes, lighting, caps, knob and hero switch provisionally approved. |
| **KF-003A-R1** | **Integrated Top Frame Refinement** *(Reviewed)* | Re-cut the deck from measured cap envelopes. Form integral navigation and arrow boundaries plus grouped function apertures. | Mechanical checks passed. Owner requested a closer fit around the right cluster. |
| **KF-003A-R2** | **Right Cluster Tightening** *(Superseded by R3)* | Refine the aperture and locally raise the shoulders around Delete, the navigation column, and the arrow cluster. Deliver four matched-studio review outputs. | Demonstrated that fixed R1/R2 key centers could not form independent nav/arrow separators; triggered KF-LAYOUT-001. |
| **KF-003A-R3** | **Alternative A Canonical Layout Integration** *(Approved / Geometry Freeze)* | Integrate KF-LAYOUT-001 Alternative A (8 relocated key centers) on the clean flat R1 top deck; adapt switch plate, PCB, acoustic layers, and front-right gasket/shelf; deliver six matched OptiX review outputs. | Owner approved R3 as canonical digital product geometry; 14/14 geometry checks and 63-sample/9-depth sweeps passed; verified backup archived under `backups/kf003a-r3-approved/`. |
| **KF-003B** | **Production Stills & Real-Time Asset** | Prepare editorial stills (`AVIF`/`WebP`) and a separate optimized `kf01_studio.glb` staging asset with instancing and material slots. | Production stills approved, and `kf01_studio.glb ≤ 2.5 MB` verified in a glTF viewer with `≤ 40` draw calls. |
| **KF-004** | **Frontend Scaffold & Design System** | Initialize minimal React + TypeScript + Vite + Tailwind CSS project; implement semantic `--kf-*` tokens, Swiss grid primitives, self-hosted variable typography, responsive navigation, and Hero + Engineering Bento + Material Library + Closing sections. | Clean typecheck/build; Hero `LCP < 2.2s`; `CLS < 0.05`; WCAG AA contrast & reduced-motion verified. |
| **KF-005** | **Interactive Mechanical Anatomy & Switch Lab** | Build the 9-layer Interactive Mechanical Anatomy explorer and the 3-switch Switch Lab (interactive keypress animation, SVG force-travel curves, optional muted-by-default sound preview). | Full keyboard & touch accessibility (`44×44px` targets); smooth transitions on desktop and mobile. |
| **KF-006** | **Build Studio (Real-Time 3D Configurator)** | Integrate lazy-loaded R3F + Three.js scene with `kf01_studio.glb`, orbit presets, real-time case/keycap/accent/switch/plate swapping, procedural Assembled ↔ Exploded transition, config summary, `localStorage` save, shareable URL state, and static WebGL fallback. | `60 fps` on desktop, `≥ 30 fps` on iGPU/mobile; `frameloop="demand"` idle verified; fallback tested with WebGL disabled. |
| **KF-007** | **Polish, Performance Audit & Release Prep** | Cross-device responsive QA, Lighthouse/Core Web Vitals pass, bundle/asset audit, accessibility audit, and final documentation update for optional deployment. | All budgets in `docs/ARCHITECTURE.md` met; zero console errors; ready for user-directed release. |
