# KEYFORM — Development Roadmap

Each phase ends with a concrete verification gate and user approval before advancing.

| Phase | Name | Scope & Primary Deliverables | Exit Criteria |
| :--- | :--- | :--- | :--- |
| **KF-001** | **Project Foundation & Product Architecture** | Verify workspace & Git, define KF—01 product spec (verified standards vs. fictional specs), mechanical hierarchy, creative direction, website IA, minimal tech stack, asset pipeline, and roadmap. | All foundation docs internally consistent, local Git checkpoint committed, and phase approval received. |
| **KF-002** | **Blender Master Modeling (`KF—01`)** *(Owner review)* | Build the editable external master, canonical 81-key layout, all nine assemblies and controls, and eight neutral review stills. | Validate pitch and placement, sweep assembled-to-exploded and downstroke interfaces, document intended contacts and approximations, and obtain geometry and product design approval. |
| **KF-003** | **Cycles Lookdev, Static Renders & GLB Export** | Build *After Hours* Cycles studio lighting rig, author anodized/PBT/brass/Poron materials, render editorial stills (`AVIF`/`WebP`), and export + optimize `kf01_studio.glb` with instancing and material slots. | Hero/bento/material/switch renders approved; `kf01_studio.glb ≤ 2.5 MB` and verified in glTF viewer with `≤ 40` draw calls. |
| **KF-004** | **Frontend Scaffold & Design System** | Initialize minimal React + TypeScript + Vite + Tailwind CSS project; implement semantic `--kf-*` tokens, Swiss grid primitives, self-hosted variable typography, responsive navigation, and Hero + Engineering Bento + Material Library + Closing sections. | Clean typecheck/build; Hero `LCP < 2.2s`; `CLS < 0.05`; WCAG AA contrast & reduced-motion verified. |
| **KF-005** | **Interactive Mechanical Anatomy & Switch Lab** | Build the 9-layer Interactive Mechanical Anatomy explorer and the 3-switch Switch Lab (interactive keypress animation, SVG force-travel curves, optional muted-by-default sound preview). | Full keyboard & touch accessibility (`44×44px` targets); smooth transitions on desktop and mobile. |
| **KF-006** | **Build Studio (Real-Time 3D Configurator)** | Integrate lazy-loaded R3F + Three.js scene with `kf01_studio.glb`, orbit presets, real-time case/keycap/accent/switch/plate swapping, procedural Assembled ↔ Exploded transition, config summary, `localStorage` save, shareable URL state, and static WebGL fallback. | `60 fps` on desktop, `≥ 30 fps` on iGPU/mobile; `frameloop="demand"` idle verified; fallback tested with WebGL disabled. |
| **KF-007** | **Polish, Performance Audit & Release Prep** | Cross-device responsive QA, Lighthouse/Core Web Vitals pass, bundle/asset audit, accessibility audit, and final documentation update for optional deployment. | All budgets in `docs/ARCHITECTURE.md` met; zero console errors; ready for user-directed release. |
