## P2-01 — Disabled-selected pose button contrast

In static fallback mode every pose button is disabled, and the selected pose carries `aria-pressed='true'`. The `:disabled` rule later in the file won the cascade over the selected state and forced `--env-muted-on-surface` (#505751) onto the forest selected background (#294b3b), measuring **1.30:1**.

Fix: a scoped rule after the disabled rule keeps the selected state's porcelain text while preserving every disabled affordance. Disabled semantics, `opacity: 0.58`, `cursor: not-allowed`, the forest selected background, and all behavior are unchanged; the unselected disabled button is untouched by design.

```css
.kf-anatomy__pose-btn:disabled[aria-pressed='true'] {
  color: var(--kf-porcelain);
}
```

Measured computed styles (`.tmp/kf009/p2-evidence.json`, static fallback at first visit):

| Button state | Before | After |
| --- | --- | --- |
| Explode, `disabled` + `aria-pressed='true'` | rgb(80,87,81) on rgb(41,75,59) = **1.30:1** | rgb(248,246,240) on rgb(41,75,59) = **8.98:1** |
| Assemble, `disabled` + `aria-pressed='false'` | rgb(80,87,81), transparent bg = 2.82:1 | unchanged (2.82:1) |

Disabled state preserved after the fix: `disabled: true`, `opacity: 0.58`, `cursor: not-allowed` at 768×1024, 1024×768, and 1440×900. The selected-disabled treatment now matches the enabled selected styling (porcelain on forest), so the only change is readability.

## P2-02 — Build Studio static stage width at 768 px

At widths where the sticky-stage rule applies and `33svh` actually clamps the canvas height (640–1023 px with tall viewports), the `.kf-viewport__canvas` width was `auto`, so the browser re-transferred the clamped height through `aspect-ratio: 16 / 10` and shrank the stage inside its column. At 768×1024 the canvas pinned at 541 px inside a 689 px stage (QA approximated the container as 705 px), leaving a dead 147 px band beside the photography.

Fix: give the canvas a definite width inside the sticky-stage query. When the height cap bites, the stage now fills its column instead of shrinking; when it does not bite (narrow phones), the 16/10 behavior is untouched. Photography keeps `object-fit: cover` (cropped, never stretched), no camera or markup changed, and the live 3D slot follows the element as before.

```css
.kf-studio__viewport-col .kf-viewport__canvas {
  aspect-ratio: 16 / 10;
  width: 100%;
  max-height: 33svh;
}
```

### Vercel root-domain static hosting (`vercel.json`)

Eight header rules, mirroring the reviewed local preview policy in `tests/scripts/serve-dist.mjs`:

| Paths | Headers | Rationale |
| --- | --- | --- |
| `/assets/kf01/*.glb` | `Content-Type: model/gltf-binary`, immutable 1y | Versioned-by-directory 3D models |
| `/assets/*` | immutable 1y | Hashed Vite JS/CSS/fonts (and the versioned model directory) |
| `/audio/kf01-v2/*` | `Content-Type: audio/wav`, immutable 1y | Opt-in switch samples, versioned path |
| `/media/kf-008a/*.avif` / `*.webp` | `image/avif` / `image/webp`, immutable 1y | Owner-approved derivatives; content frozen by the SHA-256 inventory — changes require a new version directory |
| `/` and `/index.html` | `no-cache` | HTML revalidates per request (ETag/304) |
| `/favicon.svg` | `image/svg+xml`, `no-cache` | Root-level, not versioned |

All asset references in the built output are root-relative (`/assets/…`, `/media/…`, `/audio/…`), which is correct for root-domain hosting. Compression: the platform serves gzip/Brotli for text types automatically; AVIF/WebP/GLB/WAV are already-compressed binaries and are served uncompressed by design. **Per the KF-009 work order, headers, MIME types, and compression are NOT assumed to work until verified on the deployed origin.** Post-deploy verification checklist (run against the live origin):

```
curl -sI https://<origin>/                     # expect cache-control: no-cache
curl -sI https://<origin>/assets/index-*.js    # expect cache-control: ...immutable, content-encoding: br or gzip
curl -sI https://<origin>/assets/kf01/kf01-kf004b-b3.1/models/kf01_exterior_b21.meshopt.glb  # model/gltf-binary
curl -sI https://<origin>/audio/kf01-v2/linear-45/down-01.wav                                # audio/wav
curl -sI https://<origin>/media/kf-008a/avif/OR01-provisional-desktop-hero-1600w.avif        # image/avif
```
